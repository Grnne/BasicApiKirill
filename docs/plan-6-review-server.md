# План 6: исправления по ревью бэкенда

Ревью 2026-10-02: пять срезов (вход и безопасность, сообщения, права доступа, события и
синхронизация, хранилище и эксплуатация), находки перепроверены по коду. Один пункт — один коммит,
баг сначала воспроизводится падающим тестом, изменённый SQL — интеграционным тестом. Короткие
проверки по ходу (`test.ps1 -SkipIntegration` + затронутые интеграционные тесты); коммиты — пачкой
в конце, затем один полный `test.ps1` и UI e2e.

Решения пользователя: регистрация — переключатель экземпляра (по умолчанию открыта); REST
проверяет живую сессию с кешем; права админов — как в Telegram; в план — все подтверждённые.

## Высокие

**П1. Фото не роняет API по памяти.** PNG/GIF Skia декодирует только в полный размер: 50 Мп —
200 МБ нативной памяти плюс копия при лимите контейнера 256 МБ. Лимит пикселей для форматов без
уменьшения при декодировании — по бюджету памяти, без лишней копии пикселей.

**П2. Обновление токена не возвращает закрытый вход.** Неудачная ротация — новая сессия только
если строку заменил другой refresh и семейство живо; повтор в окне — атомарно с проверкой
семейства; вставка сессии не воскрешает удалённое устройство.

**П3. Миграции без таймаута команды из строки подключения:** индекс на большой таблице
строится минуты, а 30 с запроса откатывали миграцию и останавливали запуск. Раньше индексов
П4 — они как раз такая миграция.

**П4. Удаление группы с историей.** Индексы на ссылки на сообщения (`reply_to_message_id`,
`forward_from_message_id`, `forward_from_chat_id`, `hidden_messages(message_id)`,
`user_drafts.reply_to_message_id`): каскад не сканирует `messages` на каждую строку.

**П5. Ссылки на загрузку.** После `complete` или отказа загрузка по старой ссылке не меняет
проверенный файл и не оставляет объектов без строки; размер ограничен.

## Средние

**П6. «В сети» при знакомстве — с учётом приватности и блокировок.**

**П7. Права админов как в Telegram.** Админ выдаёт новому админу и участникам только те права,
что есть у него самого; новый админ получает пересечение прав по умолчанию с правами назначившего.

**П8. Отправка после исключения.** Право писать и участники — под блокировкой чата внутри
транзакции; удалённая в этот момент группа — 404, а не 500. Так же у пересылки.

**П9. Статусы прочтения в группах не сбиваются при вступлении и выходе.**

**П10. REST проверяет живую сессию.** Семейство сессии из `sid` — живое; ответ кешируется
ненадолго, выход и отзыв сбрасывают кеш сразу.

**П11. `JoinChat`: лимит вызовов и без гонки с исключением.**

**П12. Рассылка outbox не ждёт медленного клиента внутри транзакции** — сначала доказать тестом,
иначе отложить.

## Менее важные

**П13. Папки:** выход из группы не ломает правку папки; одновременная правка не воскрешает
удалённую папку.

**П14. Правка сообщения с упоминанием вышедшего участника.**

**П15. Синхронизация:** порог «слишком отстал — снимок»; дыра в середине страницы журнала.

**П16. Caddy не пишет в лог токены и подписи ссылок.**

**П17. Мелочи:** `/signalr-docs` в проде; `%` и `_` в поиске; курсор `messages/after` при пустом
ответе; чистка файлов — объект в хранилище до строки.

**П18. Регистрация: переключатель экземпляра** — открыта / закрыта / по приглашению.
