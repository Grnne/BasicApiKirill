Подключение: wss://host/hubs/chat?access_token={jwt}
Аутентификация: JWT Bearer (передаётся в query string access_token)
← REST API

📤 Client → Server (вызываемые методы)

Client → Server JoinChat(chatId)
Подписаться на события чата. Вызывается после открытия чата на клиенте. Только участник чата может присоединиться.
ПараметрТипОписание
chatIdGuidID чата
Client → Server LeaveChat(chatId)
Отписаться от событий чата. Вызывается при закрытии чата на клиенте.
ПараметрТипОписание
chatIdGuidID чата
Client → Server SendMessage(chatId, text)
Отправить сообщение в чат. Сообщение сохраняется в БД и рассылается всем участникам. Только участник чата может отправлять сообщения.
ПараметрТипОписание
chatIdGuidID чата
textstringТекст сообщения
Самое важное: После отправки сервер генерирует 2 события: MessageCreated (в группу — полное сообщение) и ChatListUpdated (каждому участнику лично — текст обрезан до 100 символов).
Client → Server Typing(chatId, isTyping)
Уведомить собеседников о статусе печатания. Рассылается всем в группе чата.
ПараметрТипОписание
chatIdGuidID чата
isTypingbooleantrue — начал печатать, false — перестал

📥 Server → Client (подписка на события)

Server → Client MessageCreated
Новое сообщение в чате. Получают только те, кто подписался на чат (вызвал JoinChat). Содержит полный текст сообщения.
АргументТипОписание
messageMessageDtoПолное сообщение
Клиент: добавить сообщение в ленту + обновить превью в списке чатов.
Server → Client ChatListUpdated
Обновление последнего сообщения в чате. Получают все участники чата (даже те, кто не открывал чат). Текст обрезан до 100 символов.
АргументТипОписание
chatIdGuidID чата
messageMessageDtoСообщение (текст ≤ 100 символов)
Клиент: только обновить превью в списке чатов, НЕ добавлять в ленту.
Server → Client ChatCreated
Создан новый чат, в который вас добавили. Событие приходит при создании приватного чата (через POST /api/chats/private/{userId}).
АргументТипОписание
chatIdGuidID нового чата
dtoChatCreatedEventDtoИнформация о чате
ChatCreatedEventDto:
ПолеТипОписание
typestring"private" или "group"
titlestring?Название группы (null для приватных)
companionNamestring?Имя собеседника (для приватных)
companionUsernamestring?Username собеседника (для приватных)
Клиент: добавить чат в список чатов + вызвать JoinChat(chatId) для подписки на сообщения.
Server → Client UserOnlineChanged
Статус онлайн/офлайн пользователя. Получают все участники общих чатов.
АргументТипОписание
userIdGuidID пользователя
isOnlinebooleantrue — онлайн, false — офлайн
Server → Client TypingChanged
Статус печатания собеседника. Получают все в группе чата.
АргументТипОписание
chatIdGuidID чата
userIdGuidID пользователя
isTypingbooleantrue — печатает, false — перестал

🔄 Автоматические события (OnConnected / OnDisconnected)

OnConnectedAsync — при подключении пользователь добавляется в _onlineUsers, и всем участникам общих чатов отправляется UserOnlineChanged(userId, true).
OnDisconnectedAsync — при отключении пользователь удаляется из _onlineUsers, и всем участникам общих чатов отправляется UserOnlineChanged(userId, false). Если у пользователя остались другие активные подключения, офлайн не отправляется.
